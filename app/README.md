# MissileNotes app

Flutter iOS + Android app for MissileNotes. Take or pick a photo of a page
with the printed ArUco marker, and the app scans it on-device and lets you
share the result.

- `lib/pipeline/` — Dart port of the Python reference pipeline in
  `../missilenotes/`, built on `opencv_dart` and `tflite_flutter`.
- `lib/scan_service.dart` — runs scans on a long-lived worker isolate.
- `lib/home_screen.dart`, `lib/result_screen.dart` — capture → scan → share.
- `test/fixtures/` — parity fixtures generated by
  `../scripts/export_fixtures.py`.

```bash
flutter pub get
flutter analyze
flutter test --concurrency=1
flutter run   # on a connected device
```

See the [root README](../README.md#mobile-app) for the model contract, the
Linux test skip, and iOS signing.
